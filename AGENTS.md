# Discord interface requirements

- Use Components v2 for multi-line and structured bot responses, including setup,
  diagnostics, guides, errors with explanations, and confirmations. Use Markdown
  Text Displays, Containers, Separators, and images where useful.
- Plain message content is appropriate for standalone one-line replies.
- Keep edits to an existing Components v2 message in v2, including terminal states;
  Discord does not allow removing its Components v2 flag.
